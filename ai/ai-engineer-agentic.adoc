=== Day 1: Build Your First Autonomous AI Agent with n8n (No-Code Demo)

We will build agents through code. But n8n is a great drag and drop way to showcase
the possibilities. It's an automation platform.

`n8n.io` => Course uses the cloud option.

[IMPORTANT]
====
The idea of agentic AI is that it's about finding ways to glue together different
calls to LLMs. Like different messages to Chat-GPT one after the another. In order
to achieve a goal.
====

AI Agent => It's a loop, that calls an LLM with tools to achieve a goal.

**We will lay a workflow for an agent that does stuff for us**

The idea is to introduce many concepts that we will later refine, but through an
interactive session. So the n8n demo showcases a really simple workflow.

- When we receive a chat message => An AI Agent reacts.

An AI Agent requires three things:

- Chat Model: You need an LLM, the vendors right now are many. Like OpenAI, Google
(Gemini), OpenRouter. Google has cheap models, and apparently OpenRouter has even
free models. OpenAI => Requires an account, it will come with a key. And you can use
your account. (Example of one version: GPT-5.4-mini)
- Memory: Simple Memory => Now we have a chat with an agent with an LLM, with simple
memory
- Tool

Within n8n you can chat, and then the AI Agent can react to your chat messages.
You will see within the diagram the different components lighting up (in green).

[NOTE]
====
After this small setup you might go ahead and say: **Okay, but this is just like
chatting with ChatGPT**. Which is true. There's nothing Agentic about that.
====

==== Making this Agentic

**Tools:** What does it mean to give your AI a tool?

There are tons of tools that can integrate with tons of different platforms that
allow the AI Agents to make a lot of things.

**MarketStack** => There's a MarketStack tool. This is a tool that allows to retrieve
stock market prices. And it's free for 100 usages a month (-ish). (You need to get
an API key from there though)

You can setup the tool with different parameters (that will vary depending on the tool
of course), and after you are satisfied with the configuration you can add the tool.

**We can still talk to the AI Agent, but because of the tool that we added, we can
now interact with stock prices within the prompts that we might give the Agent**

And thanks to n8n, you should be able to see the Tool component lighting up in green,
because the Agent used the Stocks tool to retrieve information.

[NOTE]
====
But this still. **DOES STILL FEEL LIKE AN LLM WITH A SIMPLE EXTRA INTERFACE**
====

"Autonomous" => This is the glittery idea that people get. That's what also makes
an Agent truly Agentic. In order to reach that, we should add more tools to the
Agent.

What if...

- We add a Google Sheets tool (you can connect with your Google Account)
	- We can configure one sheets tool to be able to read Sheets
	- We can configure another sheets tool to be able to write Sheets

And yeah, this is a great selling lesson. With the tools in place, it's now up
to you to prompt the LLM correctly. But in short the demo did this:

- It simulated in a google sheet a shares portfolio. Of 2 tickers. It asked the
LLM what's the value of the portfolio
	- It used Stock Exchange's tool to get the info and then run calculations
	against what the google sheet stated
- And then after, the instructor prompted the model again, to suggest what stock
should we buy, and put that suggestions in the sheet
	- By again, using its LLM knowledge and Stock Exchange, it wrote into the
	Google Sheet a ticker and the number of shares
	- It also asked if you wanted something more defensive, and again wrote another
	ticker with its number of shares

In short, this is autonomous, the AI can make decisions, and through its configured
tools it can then take action.

=== Your First OpenAI API Call and Chaining LLM Calls in Python

````
messages = [{"role": "user", "content": "Tell me a fun fact"}]
````
Be aware of the data type of the message to send to OpenAI. It's an array, with
a dictionary as a first element.

````
response = openai.chat.completions.create(model="gpt-5.4-nano", messages=messages)
print(response.choices[0].message.content)
````

Notice the API that we are leveraging. How we should create an instance that will
call to GPT with a model and our message. And then getting the response that is
nested inside some properties.

- Chaining together LLM calls, so that we get a response from the LLM, and then
get a response to that output from the same LLM

````
question = "Please propose a hard, challenging question to assess someone's IQ. Respond only with the question."
messages = [{"role": "user", "content": question}]
````

We can then send that to ChatGPT:

````
response = openai.chat.completions.create(model="gpt-5.4-mini", messages=messages)
question = response.choices[0].message.content
print(question)
````
Notice how we are using `-mini` instead of `nano`

And now we will grab that response and send it over so that the LLM answers:

````
messages = [{"role": "user", "content": question}]
messages
````

And now, we will send and get the answer:

````
response = openai.chat.completions.create(model="gpt-5.4-mini", messages=messages)
answer = response.choices[0].message.content
print(answer)
````

The response actually comes in markdown, and it's a bit hard to read on the output
console of the Cell so we can format it better and display it in a human readable
way:

````
from IPython.display import Markdown, display

display(Markdown(answer))
````

Now, we don't know if the question is correct, but we can also chain to another
LLM model to verify if this is correct:

````
message = f"""
Here is a question:
{question}

And here is a possible answer that might be correct or incorrect:
{answer}

Please evaluate if the answer is correct or incorrect.
"""

print(message)
````

And after making the message, we shall feed it:

````
messages = [{"role": "user", "content": message}]
response = openai.chat.completions.create(model="gpt-5.4", messages=messages)
print(response.choices[0].message.content)
````

Notice how we are asking to a much "smarter" LLM: `gpt-5.4`. In the course's case,
the answer was actually wrong. And so we got a big response that is not really
readable.

````
from IPython.display import Markdown, display

display(Markdown(response.choices[0].message.content))
````
With this, (reusing what the course showed us), we actually get to visualize the
response.

And that's it. Cool, honestly.

- We made multiple calls to an LLM.
- And we did series of calls to LLM. We were chaining multiple LLM calls to reach
a goal (a solution)

And now a bit of an exercise:

-First ask the LLM to pick a business area that might be worth exploring for an Agentic AI opportunity.<br/>
-Then ask the LLM to present a pain-point in that industry - something challenging that might be ripe for an Agentic solution.<br/>
-Finally have 3 third LLM call propose the Agentic AI solution. <br/>
-We will cover this at up-coming labs, so don't worry if you're unsure.. just give it a try!

[source, python]
----
# First create the messages:

messages = [{"role": "user", "content": "Pick a business area that might be worth exploring for an Agentic AI opportunity"}]

# Then make the first call:

response = openai.chat.completions.create(model="gpt-5.4", messages=messages)
print(response.choices[0].message.content)

# Then read the business idea:

business_area = response.choices[0].message.content

message = f"Tell me a pain-point within this business area: {business_area}"
messages = [{"role": "user", "content": message}]

# Then make the second call

response = openai.chat.completions.create(model="gpt-5.4", messages=messages)
pain_point = response.choices[0].message.content

## Then make the third call

message = f"Propose an Agentic AI solution for this pain-point: {pain_point} within the business area of : {business_area}"
messages = [{"role": "user", "content": message}]

response = openai.chat.completions.create(model="gpt-5.4", messages=messages)
idea = response.choices[0].message.content
 
print(idea)
----
